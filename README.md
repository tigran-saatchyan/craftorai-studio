# Craftorai Studio

Инструмент управления контентом для Instagram @craftorai.ge — мастерская 3D печати в Тбилиси.

## Функции
- **Дашборд** — метрики по постам и изделиям
- **Планировщик** — контент-план с статусами
- **Генератор** — AI-тексты для постов (русский / грузинский)
- **Хэштеги** — базовые наборы + AI-генератор под пост
- **Журнал печати** — трекер изделий (граммы, время, постобработка)

## Деплой
Статический сайт, хостится на GitHub Pages.
